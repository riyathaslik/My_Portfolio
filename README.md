## Deploy it for free — three options

**1. GitHub Pages (recommended, free forever)**
1. Create a new public GitHub repo and push this whole folder to it.
2. Go to the repo's **Settings → Pages**.
3. Under "Build and deployment", choose **Deploy from a branch**, branch `main`, folder `/root`.
4. Your site goes live at `https://<your-username>.github.io/<repo-name>/`.

**2. Netlify (free tier, drag-and-drop)**
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag this folder in. It deploys instantly with a free `.netlify.app` URL.
3. Optional: connect a GitHub repo instead for auto-redeploys on every push.

**3. Vercel (free tier)**
1. Go to [vercel.com/new](https://vercel.com/new) and import the GitHub repo.
2. Framework preset: **Other** (static). Deploy.
3. Live at a free `.vercel.app` URL.

All three: **$0**, no credit card, custom domain support if you ever want one later.
